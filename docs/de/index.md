# synthdiet-Dokumentation (Deutsch)

`synthdiet` ist eine Python-Bibliothek zum Erzeugen synthetischer
Patient\*innen mit realistischen klinischen Tableaus und zur
Simulation diätetischer Interventionen an ihnen.
